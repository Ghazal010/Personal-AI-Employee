# 📊 Obsidian Installation Guide - Step by Step

## 🚀 Installation Steps (10 minutes)

### Step 1: Download Obsidian (2 minutes)

**Option A: Direct Download**
```bash
# Browser mein open karo:
open https://obsidian.md/download
```

**Option B: Using Homebrew (if installed)**
```bash
brew install --cask obsidian
```

### Step 2: Install Obsidian (2 minutes)

1. **Downloaded file kholo:**
   - Downloads folder mein jao
   - `Obsidian-X.X.X.dmg` file double-click karo

2. **Install karo:**
   - Obsidian icon ko Applications folder mein drag karo
   - Wait for copy to complete

3. **Open karo:**
   - Applications folder kholo
   - Obsidian double-click karo
   - "Open" click karo (security prompt pe)

### Step 3: Open Your Vault (3 minutes)

1. **Obsidian welcome screen:**
   - "Open folder as vault" button click karo

2. **Select vault folder:**
   - Navigate to: `/Users/user/Documents/GitHub/Personal AI Employee/`
   - Select: `AI_Employee_Vault` folder
   - "Open" click karo

3. **Trust vault:**
   - "Trust author and enable plugins" click karo
   - (Yeh aapka khud ka vault hai, safe hai)

### Step 4: View Dashboard (1 minute)

1. **Dashboard kholo:**
   - Left sidebar mein `Dashboard.md` dikhega
   - Click karo to open

2. **Explore:**
   - Folders expand karo (Inbox, Needs_Action, Done)
   - Files click karke dekho
   - Links follow karo (blue text)

### Step 5: Customize (Optional - 2 minutes)

1. **Settings kholo:**
   - Bottom left corner → Settings icon (⚙️)

2. **Appearance:**
   - Theme: Light/Dark choose karo
   - Font size adjust karo

3. **Editor:**
   - Line numbers enable karo (optional)
   - Vim mode (if you like vim)

## 🎮 Using Obsidian Dashboard

### Navigation

**Left Sidebar:**
- File explorer
- Search
- Bookmarks

**Main Area:**
- Current file view
- Edit/Preview mode toggle

**Right Sidebar:**
- Outline
- Backlinks
- Tags

### Quick Actions

**Open file:**
- Cmd+O → Quick switcher
- Type filename → Enter

**Search:**
- Cmd+Shift+F → Search in all files

**Create new note:**
- Cmd+N → New note

**Toggle edit/preview:**
- Cmd+E → Edit mode
- Cmd+P → Preview mode

### Dashboard Features

**Status Overview:**
- See counts of Inbox, Needs_Action, Done items
- View recent activity
- Check alerts

**Quick Links:**
- Click [[Inbox/]] to see all inbox items
- Click [[Needs_Action/]] for pending tasks
- Click [[Done/]] for completed items

**Navigation:**
- Click any link to jump to that file/folder
- Use back button to return

## 🎯 Daily Workflow with Obsidian

### Morning Routine:

1. **Open Obsidian**
   ```bash
   open -a Obsidian
   ```

2. **Check Dashboard:**
   - View pending items count
   - Read alerts
   - Check priorities

3. **Review Needs_Action:**
   - Click [[Needs_Action/]]
   - Open each item
   - Plan your day

### Throughout Day:

1. **Monitor Updates:**
   - Obsidian auto-refreshes files
   - New emails → New action files appear
   - Dashboard updates automatically

2. **Process Items:**
   - Open action file
   - Read details
   - Take action (send email via Claude Code)
   - Move to Done/ folder

3. **Move Completed Items:**
   - Right-click file
   - "Move file to..." → Done/
   - Or drag and drop

### Evening Review:

1. **Check Done folder:**
   - See what you accomplished
   - Review completed items

2. **Plan tomorrow:**
   - Check remaining Needs_Action items
   - Set priorities

## 🔧 Troubleshooting

### Obsidian won't open vault

**Solution:**
```bash
# Check vault exists
ls -la "/Users/user/Documents/GitHub/Personal AI Employee/AI_Employee_Vault"

# If exists, try opening again
open -a Obsidian
# Then: Open folder as vault → Select AI_Employee_Vault
```

### Files not showing

**Solution:**
1. Settings → Files & Links
2. Check "Excluded files" is empty
3. Reload vault: Cmd+R

### Dashboard looks broken

**Solution:**
1. Switch to Preview mode (Cmd+P)
2. Or: Settings → Editor → Default view mode → Reading view

### Can't edit files

**Solution:**
1. Click "Edit" button (top right)
2. Or: Cmd+E to toggle edit mode
